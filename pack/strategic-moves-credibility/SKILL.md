# 策略性行动与置信度评估

## R 原文
"先行动包含了两方面的含义：首先，你的行动对于别人来说必须是可观察的（observable）；其次，它是不可逆的（irreversible）。"（第9章9.1，L5958）"有两种方法使你的策略性行动可信：（1）在你未来的选择组合中排除'引诱行动'；（2）减少这些'引诱行动'的支付。"（9.2，L6003）"如果威胁成功了，它就不必实施了，威胁者就不用付出代价。……许诺人都力图把这种代价减小——代价只需大到使许诺有效即可。"（9.4.2，L6172）

## I 自述
核心骨架：双条件→分类→手段库→反制全链。
1. 双条件检验：真正的"先行动"必须同时可观察+不可逆；缺一即弱声明或无效声明——不可观察=对方无法反应，可逆=对方预期你反悔。
2. 三分类：承诺（无条件先行动，抓住先发优势，常是"表面劣策略"——放弃灵活换固定对方预期）；威胁（有条件反应规则："你做X我就伤害你"，宜静态遏制、强迫须配截止日期）；许诺（"你做X我给你好处"，成功后必须兑现故有真实代价）。每个威胁暗含许诺、反之亦然，两半都要可信才整体有效；暗含的一半若不可信必须明确化。
3. 置信度两大法+手段库：排除引诱行动（烧桥断后路、削减未来选择）或降低引诱行动的支付（改变自己第二阶段的收益结构）；具体手段：声誉、团队合作、证明"表面"非理性、烧桥、契约——每手段附反制检查（委托可被收回、契约可再谈判、声誉依赖重复关系存续）。
4. 非对称规则：威胁可夸大（成功则不执行），但太大反而失置信（x06"威胁太大"）；许诺只需大到"刚好改变对手选择"，规模浪费是纯成本。
5. 反制清单（p12要点）：对声誉型威胁→保密行动/给台阶；对强迫型→腊肠策略逐小步蚕食（每步都在对方截止线之下）+预期对方会设截止日期；对不可逆+第三方执行型→反制空间小，只能提前预防。
6. 核心防误读："威胁成功则不必执行"——未兑现的威胁不是失效，是成功。

## A2 触发
股票场景与语言信号（中英双写关键词）：
1. "央行这个表态算数吗"（central bank commitment / forward guidance）→ 双条件+手段库打分。
2. "大股东增持/回购公告含金量几分"（share buyback credibility）→ 烧桥程度：注销>分批>承诺>口头。
3. "庄家/对手放话要砸到某某价位，信吗"（threat assessment / jawboning）→ 威胁上界检验：执行成本>执行意愿→嘴炮。
4. "公司说要全额收购/要约，怎么核"（takeover seriousness）→ 是否已交保证金/聘顾问/董事会决议等不可逆步骤。
5. "被要挟了（恶意收购、逼仓）怎么应对"（counter-move / salami tactics）→ 反制清单：保密、给台阶、腊肠+防截止日期。

## E 执行
1. 双条件判定：该行动别人能观察到吗（公告/盘面可见）？能反悔吗（法律/资金/技术上是锁定还是意向）？记录✓✗。
2. 分类与暗含检查：归入承诺/威胁/许诺；找出暗含的另一半（威胁里的许诺"你不做X我不伤你"、许诺里的威胁）并测其置信度；任一半不可信→须明确化补强。
3. 置信度打分：逐项过手段库（声誉绑定/团队监督/表面非理性/烧桥/契约与委托），每项写明成立依据与被撤销的路径；输出等级（强/弱/无效）。
4. 规模校验：威胁是否超出可执行上界（过大→降级为概率威胁，转 celue-09）；许诺规模是否"刚好改变对手选择"（过大→浪费）。
5. 反制预案：按对方行动类型查反制清单，输出2-3条可执行应对。
完成标准：每个声明有双条件标记+分类+置信度等级+暗含许诺检查记录；反制预案有触发条件。
判停点：双条件信息不足（无法确认是否锁定资金）→输出"待验证清单"而非等级；发现对方以边缘政策方式渐进加码→转 celue-09 双阈值框架。
输入契约：声明原文、发布主体、可观察渠道、不可逆证据（资金划转/公告法律效力）、对方历史兑现记录。缺先问。
输出契约：置信度等级（强承诺/弱承诺/无效声明）+打分明细；威胁可信度判定规则=执行成本≤执行意愿上限；许诺规模判据=恰好改变对手最优反应的最小代价；不输出买卖指令。

## B 边界
反场景：纯信息解读（无行动意图的表态）走 celue-05；对手无反应能力（散户对指数）谈威胁无意义；一次性匿名对手无声誉机制可用，手段库失效。
书中警告的失败模式（x06，第9.4.1/9.6）：不可信威胁与"威胁太大"——退出防御联盟的威胁"代价太大、风险太高，美国不会去执行，所以并不可信"；威胁大小与置信度成反比，超上界的威胁反而劣于小威胁。纪律：只有执行成本在承受意愿之内、或有制度化执行机制（自动触发条款）的威胁才值得定价。
阶段0批判中的作者盲点：不可逆是程度而非0-1（回购可中止、要约可修改，法律锁定也有例外条款）；"表面非理性"建议在市场化对手面前可能引火烧身且道德风险未讨论；手段库默认对手理性识别置信度，散户常把表演当烧桥；未讨论声誉跨市场、跨主体的迁移与清洗。
易混淆相邻方法论：与 celue-05 区分（动机维度vs执行维度，见A2）；与 celue-09 区分（本卡判"威胁可信与否"，celue-09算"概率威胁的可行域数值"）；与celue-10区分（拍卖里的出价承诺是机制规则约束，不是本卡的策略性先行动）；p09双条件、p10威胁许诺规则、p11手段库、p12反制清单（rejected）已全部并入本卡I/E段。
