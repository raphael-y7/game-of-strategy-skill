# 混合策略与随机化执行

## R 原文
"埃弗特的有利用佐证的混合必须具备一个特点：纳芙拉蒂洛娃防守DL或CC来应对时得到的支付相同；它必须让纳芙拉蒂洛娃在她的两个纯策略之间无差异。我们称之为对手无差异性质。"（第7章7.2.1，L3783）"缺乏固定的模式意味着在任意选择历史后，下一次选择DL与CC的概率和以前都是一样的。"（7.8，L4150）"在对非零和博弈中的混合策略均衡进行解释或应用时应慎之又慎。"（7.9.2，L4222）

## I 自述
核心骨架：
1. 适用前提：同时行动的博弈、无纯策略纳什均衡（或需要对对手隐藏模式）、且利益近似直接对立（零和）。三者缺一则本卡慎用——非零和场景该性质缺乏动机支撑。
2. 计算（对手无差异性）：设我方选行动1的概率为p。令对手在他的各纯策略上得到的期望支付相等，解出p——这个p是"使对手无法利用"的均衡混合；同理令我的各纯策略期望支付相等解出对手的概率q。注意：我的均衡混合概率只由对手的支付决定，与我自己的支付无关（比较静态：p04要点）。
3. 排障：解出负概率或大于1的概率→该策略组合下无混合均衡→回退找纯策略均衡；3×3及以上出现负概率→把该纯策略概率设为0，在剩余策略上重解，并复查被剔除策略的支付确实更低。
4. 执行（防被识别）：概率≠机械交替；"过度交替"本身是可被识别的模式（负自相关）。执行端用外部随机装置（秒针法：60秒×目标概率=分界秒数；手表不能太精确，且须向第三方事先交代期望逻辑以免坏结果担责）。
5. 利用对手错误：若对手偏离均衡混合（如"石头最好"式幼稚固定），直接用纯策略最优反应，不必自己再随机。
6. 适用边界：零和体育/军事类对抗（罚球、发球、护卫调度）、高频重复且对手可观察我历史的场景（算法识别散户下单模式）；市场整体多空解读（非零和）不适用。

## A1 案例
类型：field data（职业体育），来源：第7章7.9.1图7-12欧洲联盟杯罚球（candidates/cases.md c06）
支付表（罚球人成功率）：左58/95，右93/70。用对手无差异性：令守门员无差异 95−37p=70+23p → p=25/60≈38.3%（罚球人选左）；令罚球人无差异 7+35q=30−25q → q=25/60≈41.7%（守门员扑左）。均衡下双方各纯策略成功率均为79.6%。实测：罚球人40.0%选左、守门员41.3%扑左，理论38.3%/41.7% vs 实测几乎重合，对手无差异性在田野数据成立。温网对照（7.9.1，c05）：沃克与伍德斯40种发球情形中39种正反手得分率统计上相等，但选手"过度交替"——偏差存在却小到回球者无法利用。数值全部与转写稿L4205-4207一致，阶段1.5 V2数值评测通过。

## A2 触发
股票场景与语言信号（中英双写关键词）：
1. "我的下单会不会被算法盯上？"（pattern recognition / algorithmic front-running）→ 自查下单时间/方向/手数的伪随机模式，改外部随机装置执行。
2. "主力今天到底买还是卖？"（smart money guessing）→ 若是竞价撮合对手盘且互猜，先过celue-02找纯策略均衡；无纯均衡才转本卡算混合概率。
3. "庄家洗盘节奏有没有规律？"（fake randomness exploitation）→ 识人方向：检验对手序列的负自相关与按自身收益倾斜，用其模式获利（x12两检验）。
4. "打新/抢筹该按什么比例随机撤单？"（order randomization）→ 仅当与对手近似零和、高频重复才成立。
5. "量化对手的执行概率怎么估？"（equilibrium mixing frequency）→ 用对手支付数据解无差异方程，勿用自己的支付。
与相邻卡区分：celue-02找的是纯策略均衡格（互为最优反应），本卡处理无纯均衡时的概率混合与执行防识别；celue-12从种群比例（多态型）解释"人群层面的混合"，个体不随机也成立，本卡要求单个参与人真随机；celue-09是故意制造可控风险的序贯策略，不是同时博弈随机化。

**相邻区分（定稿）**：与 celue-12 的区分（定稿）：本卡要求单个参与人用外部随机装置真随机（个体层面、零和前提），celue-12 的多态型说明"人群按比例混合"而每个个体都是纯策略（种群层面、无需随机化）——市场里的"混合"多数是多态型加总，套本卡前先问这是个体随机还是种群比例。
## E 执行
1. 前置检验：确认同时行动+无纯策略均衡（先过celue-02最优反应分析）+利益近似零和（对手赢=我输的量级）。任一条不满足→判停。
2. 建表：2×2支付表（零和可只写一方支付）；多策略先看有无显然劣策略剔除（剔除后复查）。
3. 解无差异方程：对手在各纯策略上期望支付相等→解出我的p；我对各纯策略期望支付相等→解出对手的q。公式（2×2，我的策略行支付a₁/a₂对应对手两列）：对手无差异 a₁₁p+a₁₂(1−p)=a₂₁p+a₂₂(1−p)。
4. 排障：p∉[0,1]→无混合均衡，回退纯策略；某策略概率为负→设0后重解，并验证被剔除策略支付不高于均衡支付。
5. 执行方案：写明随机装置与分界（秒针法：目标概率×60=秒数分界）；禁止按"上次结果"调整（无模式）；向更高权威事先交代期望逻辑。
6. 利用偏差检验：对对手历史序列做负自相关检验与收益倾斜检验，显著→用纯策略针对性反应。
完成标准：均衡概率可复算（方程与解留痕）；执行规则不含任何依赖历史的项；零和前提检验通过并留痕。
判停点：非零和（如对手是基本面配置盘）→按x03"慎之又慎"放弃均衡预测，只保留"防自身模式被识别"的执行建议；支付无法量化→只给"使用外部随机装置+避免过度交替"的定性纪律。
输入契约：双方支付表（零和至少一方完整）、是否同时行动、对手历史行动序列（如要利用偏差）。
输出契约：各参与人均衡混合概率（保留一位小数百分比）+均衡期望支付+执行随机化方案（装置、分界、禁则）+零和检验结论；误差≤±1个百分点（支付四舍五入所致，须声明）。

## B 边界
反场景：市场整体多空博弈（供需双方利益不完全对立、且"混合"是个体异质性加总）不是零和混匀场景；一次性大决策（无重复、无人观察你的历史）不需要随机化——直接期望值最大化即可。
书中警告的失败模式（x03+x12，第7章7.9.2、7.8）：非零和实验室实验中参与人没有理由让对手保持无差异，自身支付提高时更多选该行动，违背"混合只取决于对手支付"，故非零和应用须慎之又慎；人伪造随机系统性过度交替且按自身收益倾斜——自查防算法识别，识人可利用，但网球数据提示该偏差常小到无法被利用。
阶段0批判中的作者盲点：零和前提把市场参与者同质化为互猜的撮合对手，忽视做市商库存与税费改变了零和性质；秒针法解决执行随机但未解决"均衡概率本身需随对手群体演化更新"（对手也在学习）；支付用成功率度量，真实交易的支付含非线性尾部（x05同源问题），均衡概率对尾部支付敏感。
易混淆相邻方法论：与频率派"掷硬币各半"直觉区分——均衡概率由支付结构决定，很少是50:50；与celue-12多态型区分（种群比例≠个体随机）；与celue-09概率威胁区分（那是序贯的可控失控，q是灾难发生概率而非行动混合概率）；p04（比较静态L3967）与p05（秒针法L4158-4166）已并入本卡，rejected不占编号。
