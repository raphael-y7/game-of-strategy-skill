# 决策规则速查 — 策略博弈（第4版）

| 能力 | 一句话规则 |
|---|---|
| 博弈分类六维度与来源路由入口 | 用行动时序/利益冲突/次数/信息/规则/协调六问给局面分类，并路由到对应能力卡。 |
| 事件博弈树逆推 | 建树后从终点结逆推，产出可核对的均衡路径与条件策略（含自然节点的概率乘积法）。 |
| 支付表与纳什均衡定位 | 最优反应分析逐格双向圈定均衡，占优剔除做快速减法，弱占优必须复查。 |
| 合作临界值计算（重复博弈与瓦解时点） | R>(C−L)/(H−C)−1 与 R>(C−D)/(H−C) 双临界加 R=(1−pδ)/(pδ) 折算，给出合作瓦解的先行指标。 |
| 混合策略与随机化执行 | 令对手无差异解出均衡混合概率；执行端防过度交替；严格限定零和场景。 |
| 信号与话语可信度判定 | 利益一致度分级+差异成本检验双通道过滤信息，辅以均衡三型判型与柠檬临界预警。 |
| 聚点与关键点位选择 | 借共同显著性线索预测多重均衡的收敛方向，并提示参照系异质时的失效。 |
| 策略性行动与置信度评估 | 可观察+不可逆双条件定强弱，承诺/威胁/许诺分类配手段库打分，附反制清单与"威胁成功则不必执行"。 |
| 集体行动与踩踏（多人博弈判据） | P(n)/S(n)曲线三型判别+边际社会获益三分解+责任分散公式，量化拥挤阶段与踩踏临界。 |
| 边缘政策概率威胁双阈值 | 有效条件与可接受条件围出可行域，p落入三段给出行动/边缘/放弃，附失控项与尾部留权。 |
| 赢家诅咒与拍卖出价 | "我是否高估+对手行为揭示什么"两问强制校验，按机制映射调整出价。 |
| BATNA谈判分析 | x=a+h(v−a−b)定成交区间，BATNA操纵与不耐烦比例y/x=r/s定实力分配。 |
| 策略拥挤与抱团瓦解（进化博弈判据） | ESS双准则+适应度阈值族（x>2/3、x>2/n、x<1/2）+鹰比例h=V/C，判策略拥挤度与瓦解条件。 |
| 机制设计与激励契约分析 | 用激励相容与参与约束双条件评估契约与信息披露机制能否诱导真实类型/真实努力 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
