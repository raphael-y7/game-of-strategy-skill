# 信号与话语可信度判定

## R 原文
"直接沟通的可信性取决于博弈双方利益一致的程度。"（第8章8.3.2，L4881）"你应该完全忽略他的建议。……唯一的均衡是你忽略你的顾问。"（8.3.3，L4920）"口头声明没有成本，因而是无用的，任何人都可以对他卖车的原因撒谎。"（斯宾塞语，第8章8.4.2，L5063）"如果'橘子'所占的比例满足……f＞0.65，价格将会起动作，否则不存在有效交易。"（8.4.2，L5059）

## I 自述
核心骨架：双通道过滤+均衡判型+市场级预警。
1. 通道一·利益一致度分级（廉价磋商可信度）：先问"他靠什么赚钱、亏了我他亏什么"。一次性关系+固定佣金→废话均衡（一切话语信息价值=0）；声誉成本+利润分成（尤其损失分担）→部分披露；长期声誉+深度绑定→完全披露。共同利益越大反而越难精确传递（利益完全冲突的零和场景话语同样不可信）；利益关联认知必须是双方共同知识，否则按低档处理。连续信息只信"区间制"粗分割——报告颗粒度越细，声誉约束越强。
2. 通道二·差异成本检验（信号甄别）：有效信号必须"不同类型模仿成本不同"——劣质类型模仿优质类型的成本≥其冒充收益。回购注销、真金白银增持、可验证的硬承诺有成本；口头指引、愿景、转发利好无成本=无效信号。成本越高、越难模仿，信号越可信。
3. 均衡判型（p08要点）：不对称信息下均衡只有三种——分离（类型各自显示，信息含量高）、混同（人人一样表态，信息含量趋零）、半分离。先辨型再解读：混同型公告集体出现≈没有信息。
4. 市场级柠檬预警：混同价 P=劣质价值+优质溢价×优质比例f；当 f 恶化使混同价跌破优质方保留价→优质者退出→比例再恶化→崩溃。先于暴雷的可查信号是"质量分布f恶化"（造假案例比例上升、审计失灵）。

## A1 案例
类型：business，来源：第8章8.3.3 投资顾问廉价磋商（cases.md c11；阶段1.5 f07 walkthrough 复算）
项目质量B(-50)/M(+1)/G(+55)三型各1/3，顾问预收2%佣金+利润20%分成但不担亏。一次性关系：说谎无成本→无论质量都报G→客户期望支付-3.73千美元→唯一均衡=完全忽略（废话均衡，L4920）。加声誉成本（谎报罚4）与20%分成后出现部分披露{非B}（报告"非B"净支付2−3=−1<0约束生效）；声誉罚4/8时完全披露{B}{M}{G}（M报G支付2+0.2−4=−1.8<0）。分级结论可复算、与原书一致。
类型：textbook，来源：第8.5.1-8.5.2 教育信号（c13；阶段1.5 f08 walkthrough 复算）：A类修课成本3000/门、C类15000/门；激励相容 60000≥160000−15000n→n≥6.67→7；参与条件 160000−3000n≥125000→n≤11.67→11；分离区间7≤n≤11。映射：只有模仿成本差异≥门槛的信号（注销式回购vs口头指引）才能分离类型。
类型：textbook，来源：第8.4.2 二手柠檬市场（c12）：好车16000/卖方保留12500，坏车6000；混同价=6000+10000f；f<0.65→好车退出→市场只剩柠檬（x13）。

## A2 触发
股票场景与语言信号（中英双写关键词）：
1. "这份研报/这个大V荐股能信几分"（research credibility / conflict of interest）→ 通道一五级分级。
2. "管理层回购/增持是真心还是做样子"（buyback signal / costly signaling）→ 通道二差异成本：注销式>库存股>承诺式>口头。
3. "业绩指引、路演表态怎么解读"（guidance / cheap talk）→ 无成本话语按废话均衡缺省，除非有声誉约束。
4. "一堆公司同时发利好公告"（pooled disclosure / no information）→ 判型：混同均衡信息含量趋零。
5. "这个板块/资产池是不是劣币驱逐良币了"（lemons premium / adverse selection）→ 柠檬临界预警：可验证质量手段失效即预警。
与相邻卡区分：celue-00 只判定信息轴存在不对称，不评可信度；celue-07 评的是"行动/承诺的置信度"（可观察+不可逆的执行问题），本卡评的是"话语与信号的信息含量"（发信人动机问题）；celue-10 处理拍卖中的报价信号，非日常信息披露；celue-11 的BATNA是谈判筹码评估。

**相邻区分（定稿）**：与 celue-07 的区分（定稿）：同一份公告先过本卡定信息含量级（他为什么说、话语可信几分），再过 celue-07 打执行置信度分（他做了什么、能否反悔）——动机过滤在前、执行打分在后，串联不互斥。
## E 执行
1. 画利益结构：发信人的收益来源（佣金/分成/声誉/持仓）、是否分担你的损失、关系一次性还是长期。缺任一项→先问，不代填。
2. 通道一定级：一次性+固定费→0级（忽略）；有声誉罚则→部分披露级（只信其"否定式"陈述）；分成+担亏+长期→完全披露级（按内容采信）。
3. 通道二检验：列出对方信号清单，逐项问"劣质类型模仿这个动作要花多少成本"；成本<冒充收益→无效信号剔除。
4. 判型与预警：观察同类信源是否人人同质表态（混同→信息≈0）；对资产池估计优质比例f与保留价，算混同价是否逼近优质方退出线。
完成标准：每条信息有定级（0级/部分/完全）+判型标签（分离/混同/半分离）+差异成本理由；柠檬预警给出临界值。
判停点：发信人利益结构完全不可查（匿名荐股、无历史记录）→按0级处理并停；信号成本无法估计→只输出"成本高低排序"不给绝对可信度数值。
输入契约：信源身份与利益结构、历史兑现记录、信号动作清单及其成本估计、资产池质量比例数据。
输出契约：可信度分级结论+信号有效性排序；柠檬临界公式 P_mix=V_bad+（V_good−V_bad）×f，优质方退出条件 P_mix<V_good_reserve（书中例：6000+10000f<12500→f<0.65崩盘）；数值误差由输入估计精度决定，须声明±档位。

## B 边界
反场景：利益完全一致（自家账户自研自用）无需过滤；完全零和信息（对手靠你亏损赚钱）话语信息价值趋零但可从其行动反读（转 celue-07/04）；公共宏观信息（人人同时获知、无发信人利益）不经本卡。
书中警告的失败模式：x07 废话均衡——"你应该完全忽略他的建议"，一次性流量型荐股（直播间、短链）缺省按0信息处理；x13 柠檬市场崩溃——f<0.65时市场彻底失效而非价格调整可解，预警信号是质量分布恶化先于暴雷。
阶段0批判中的作者盲点：声誉被建模为外生罚金，真实市场声誉可通过换个马甲归零（一次性化伪装成长期）；差异成本假设成本可观测，而"看起来昂贵的表演"（做账式回购、表决心）成本可能远低于表面；模型默认买方理性知道f，散户恰恰连f都估错；未处理监管强制披露改变信号成本结构的情形。
易混淆相邻方法论：与 celue-07 置信度（行动的不可逆性）区分——"口头承诺+执行成本"两个维度常被混为一谈：本卡问"他为什么说这个"，celue-07问"他做了什么、能不能反悔"；与celue-10两问检验区分——那是共同价值拍卖的报价前自检，本卡是日常信息流过滤；p06利益分级、p07差异成本、p08均衡判型（rejected）已全部并入本卡I/E段。
