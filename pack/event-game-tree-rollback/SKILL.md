# 事件博弈树逆推

## R 原文
"你必须从考察那些直接通向终点结的行动结开始分析。通过比较其在相应终点结上的支付，就可立即找出在这样一个结点上行动的参与人的最优选择。……沿着博弈树按照这种方法向后进行，你就可以解出整个博弈。"（第3章3.2，L860）"参与人应当前瞻博弈中将来的行动，然后倒推出当前的最优行动，这是策略的一般原理。"（第2章2.5末，L268）

## I 自述
核心骨架：
1. 建树：列参与人、行动次序、每个行动结的可行枝、终点结支付；不确定性来源引入"自然"节点并标注概率与概率来源。
2. 逆推：从直接通向终点结的行动结开始，比较支付选出该结参与人的最优枝，把该结价值替换为所选枝的终点支付，逐层向后，直到初始结。
3. 自然节点取期望：结点价值 = Σ(概率 × 下游价值)，即概率乘积法/加权和法。
4. 产出：逆推均衡（即子博弈完美均衡）的均衡路径 + 每个结上的条件策略（"如果走到这里就做X"）+ 均衡路径外各枝的解读。
5. 纪律：均衡路径之外的枝也必须计算——它们是检验威胁与许诺可信度的依据，也是"如果对手偏离我会怎么办"的预案。
6. 适用：一切事件驱动的多阶段局面——政策路径推演、并购流程节点、解禁时间线、先后手明确的资金博弈。

## A1 案例
类型：experiment（真人秀），来源：第3章3.7图3-11《幸存者》瑞奇弃赛（candidates/cases.md c15）
三人残局：鲁迪人缘极佳、决赛必胜。瑞奇赢挑战→须亲自淘汰鲁迪→得罪评委，决赛胜率仅0.4；故意输→凯莉以0.9概率赢下挑战并替他淘汰鲁迪→瑞奇决赛胜率0.6。逆推复算：放弃路径 0.9×1×0.6=0.54；继续路径 0.45×0.4+0.5×0.6=0.18+0.3=0.48。0.54>0.48，均衡=故意输掉挑战。直觉（赢下挑战保持主动）与计算相反——"以退为进"。数值与转写稿 L1161 完全一致，阶段1.5 V2 数值评测通过。

## A2 触发
股票场景与语言信号（中英双写关键词）：
1. 并购/重组事件链："过会、批复、交割各步概率多少，现在埋伏还是等落地？"（deal spread / event-driven）→ 概率乘积折算期望价差。
2. 政策路径："加息或关税分几步走，每步市场怎么反应？"（policy path pricing）→ 树上每层一个决策结。
3. 解禁时间线："大股东解禁前会不会先拉高出货？"（pre-lockup run-up）→ 逆推大股东各时点最优行动。
4. 击鼓传花："抱团还剩几棒、最后一棒是谁接？"（greater fool / last mover）→ 先判对手类型再逆推（见B）。
5. 以退为进："该不该抢这个反弹高点/龙头位？"（let it go / second-tier entry）→ 放弃表面领先换更好的后续对手结构（同c16世界杯小组赛逻辑）。
与相邻卡区分：celue-02 是同时博弈、无先后手可逆推；celue-03 算的是"合作能撑多久"的收益率临界值，不是事件路径；celue-09 把树中"自然"节点概率专题化为概率威胁可行域；celue-11 输出谈判成交区间而非路径；celue-08 处理的是人数维度的集体行动，不是两方先后手。

**相邻区分（定稿）**：与 celue-09 的区分（定稿）：本卡是通用逆推底座（建树、均衡路径、条件策略表），celue-09 把树中"自然"节点专题化为受控失控风险（双阈值可行域）——一般事件链用本卡，仅当威胁类场景需要量化灾难概率窗口时转 09。
## E 执行
1. 建树：列参与人与各阶段可行行动；不确定事件设"自然"节点；每个概率必须写明来源（历史频率/用户估计/机构一致预期）。缺支付或缺概率→先问用户，不代填。
2. 逆推：从最末层行动结开始逐层选最优；自然节点算期望 E=Σpᵢ×Vᵢ；多层自然节点连乘。
3. 输出：均衡路径一句话+条件策略表（每个行动结一格）+路径外枝标注"在什么信念下才会被选"。
完成标准：每个行动结都有唯一最优枝（支付并列时列出全部均衡路径）；结论可复述为"谁在何时做什么"；概率与支付来源全部留痕。
判停点：概率完全无法估计且用户拒绝赋值→退化为情景树，只给各分支条件结论不给单一答案；发现对手非理性或支付含公平/报复成分→先做对手分型再决定逆推是否适用（见B）。
输入契约：参与人清单、各结行动集、时序、支付（或偏好排序）、自然节点概率及其来源。
输出契约：均衡路径+条件策略表；数值保留两位小数；期望值计算误差≤±1%（由输入概率精度决定，须声明）；结论附"该结果最依赖的2-3个概率或支付"。

## B 边界
反场景：纯同时博弈（无先后信息揭示）没有树可逆推，转 celue-02；单方决策（无对手反应）是普通决策树，不是博弈树，本卡不适用。
书中警告的失败模式（x01 蜈蚣博弈，第3章3.6）：逆推预测第一步就拿走硬币，实验中仅4%的人这么做——非零和、讲声誉的人类对手会"用放弃释放合作信号"，使泡沫/合作比逆推均衡持续得更久；对照组：零和序贯博弈中职业棋手10次有10次实现逆推均衡。纪律：先判对手类型——量化零和对手（做市、算法）逆推预测良好；抱团参与者、长线联盟逆推只给瓦解下限。
阶段0批判中的作者盲点：理性共同知识假设过强；支付默认可完全量化，真实市场含流动性约束、监管处罚等难以入表的项；自然节点概率被要求外生给定，而市场价格本身会改变事件概率（内生性未处理）。
易混淆相邻方法论：与决策论决策树（无对手最优反应环节）区分；与 celue-04 混合策略（那是同时博弈的随机化，不是序贯逆推）；与 celue-09 边缘政策（那是故意在树上制造可控失控风险的特殊应用）；p01（rejected）"逆推是序贯博弈唯一正确推理方向"原理句已并入本卡R段。
