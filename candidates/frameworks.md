# 《策略博弈（第4版）》阶段1候选清单：思维模型/决策框架/推理方法/流程/排障

- id: f01
  title: 博弈分类六维度判定框架
  type: framework
  source_chapter: 第2章 2.1-2.3
  source_quote: |
    "在序贯行动博弈中，每个参与人都必须思考：如果我这样做，我的对手会怎样反应？……在同时行动博弈中，你得精明地猜测对手现在会如何行动；但你必须认识到，对手在进行其算计时也会猜测你现在会如何行动。"
  summary: |
    面对任何互动情境，先判定它是决策还是博弈，再按六个维度分类：行动时序（序贯/同时）、利益冲突度（零和/常和/混合）、重复性（单次/重复且对手是否固定）、信息结构（完美/不完美/不对称）、规则可否操纵（固定/可自订）、协议可否强制（合作/非合作）。每个维度的判定直接决定选用的解法路线：序贯→博弈树逆推；同时→支付表纳什均衡；不对称信息→信号/甄别；无强制协议→非合作解法。分类错误则后续解法全错。
  stock_application: |
    把多空博弈、政策博弈、公司行为先分类再分析：财报公布前是同时行动（猜市场预期），政策落地过程是序贯行动（央行与市场互动）；行业价格战多为非合作重复博弈；荐股信息是不对称信息博弈。避免把本应逆推的事件链当成静态同时博弈处理。
  inputs: 待分析情境的参与人、行动时序、利益结构、信息分布、协议强制力
  outputs: 六维度分类标签 + 对应解法路线选择
  missing_conditions: 六维度冲突时（如既是序贯又信息不对称）优先级排序原书未系统给出；真实市场常兼有多维特征，需分析者自行加权。

- id: f02
  title: 博弈树建模与逆推法（rollback）
  type: framework
  source_chapter: 第3章 3.1-3.3
  source_quote: |
    "你必须从考察那些直接通向终点结的行动结开始分析。通过比较其在相应终点结上的支付，就可立即找出在这样一个结点上行动的参与人的最优选择。……沿着博弈树按照这种方法向后进行，你就可以解出整个博弈。"
  summary: |
    序贯博弈的唯一正确推理方向。步骤：(1)识别参与人、行动顺序、每个决策结的可选行动与终点结支付，画出扩展式博弈树（每个结点发出枝覆盖全部可选行动）；(2)从直接连着终点结的决策结开始，选出该结行动者的最优枝；(3)把该结替换为所选结果，逐层向前推进；(4)得到从初始结到终点结的均衡路径及每个参与人的完整条件策略（含偏离均衡路径上的反应）。要点：均衡路径外的枝也必须算——先动者的选择依赖于对后续反应的预判。
  stock_application: |
    事件驱动分析底座：把并购审批（公司申请→监管否决/批准→公司撤回/诉讼）、增持回购（大股东公告→市场跟随→后续加仓/放弃）、加息周期（央行表态→市场定价→央行兑现）写成博弈树逐结剪枝，推演最可能路径与市场应计价的结果，与当前定价对比找错配。
  inputs: 参与人清单、行动顺序、各结点可选行动、各路径终点的各方支付（可用预期收益/损失替代）
  outputs: 逆推均衡路径 + 各参与人完整条件策略 + 各结点临界判断依据
  missing_conditions: 真人逆推在复杂树中经常失效（3.6实验承认偏离显著），原书未给出替代解概念；支付数值需分析者自估，原书只给教学数字。

- id: f03
  title: 纳什均衡定位：最优反应分析
  type: reasoning_method
  source_chapter: 第4章 4.2/4.4
  source_quote: |
    "最优反应分析是一种全面寻找博弈中所有可能的纳什均衡的方法。……如果'行'有占优策略，那么他对'列'的所有策略的最优反应都是一个相同的策略，所以他的最优反应将水平地排列在同一行中。"
  summary: |
    同时行动博弈的标准作业。步骤：(1)列出支付表；(2)轮流站在每个参与人立场，对对手每一种可选策略标出自己的最优反应（表中画圈）；(3)双方支付都被圈中的单元格即纳什均衡；(4)若没有任何双重圈格，则该博弈无纯策略均衡，转入混合策略分析。纳什均衡等价定义为"正确信念+最优反应"体系：各方互为最优反应、无人有单方面偏离动机。
  stock_application: |
    定位市场参与者的稳定锚点：多空对峙（加仓/离场 vs 压价/抬价）、央行与财政的搭配博弈、行业内龙头企业定价对峙。找到均衡格即市场常态；识别市场当前所处格与均衡格的偏离，判断回归压力方向。注意纳什均衡不等于集体最优——可据此解释"理性但双输"的行业格局。
  inputs: 双方（或多方）可选策略、各策略组合下的支付（收益/成本可货币化即可排序）
  outputs: 全部纯策略纳什均衡集合；无双重圈格时的"需转混合策略"判定
  missing_conditions: 均衡作为描述性预测在非零和场景实验证据弱（5.4承认）；多重均衡时如何选未在此解决（见f06聚点）。

- id: f04
  title: 占优策略筛选与重复剔除劣策略
  type: reasoning_method
  source_chapter: 第4章 4.3
  source_quote: |
    "重复剔除劣策略的过程可以剔除劣策略或缩小博弈的规模，直到不能进一步剔除为止。……重复剔除弱劣策略可能会遗漏一些纳什均衡。"
  summary: |
    在大支付表中先做快速减法：(1)找每个参与人的占优策略（无论对手怎么选都更优）；若双方都有，直接得均衡；(2)若仅一方有，对方会预判之并选自己的最优反应；(3)都无占优策略时，剔除劣策略缩小博弈，剩余小表中可能出现新的劣策略，重复剔除；(4)只剩唯一结果则博弈占优可解。排障要点：用弱占优（存在相等支付）剔除后必须回头用最优反应分析复查，弱劣策略剔除会漏掉部分均衡。
  stock_application: |
    行业竞争快速判断：先检验是否有占优策略（如产能过剩时"降价抢份额"常是龙头占优策略），一方有占优策略即可预测另一方反应；价格战、降佣竞赛的支付结构检验。用剔除法把复杂行业博弈缩到2×2再做直觉判断。
  inputs: 支付表（至少可对各方支付排序）
  outputs: 占优策略识别 / 缩小后的博弈 / 占优可解的均衡结果；弱占优剔除时的复查提示
  missing_conditions: 重复剔除要求"理性是共同知识"（剔除层数越深假设越强），原书承认由纯理性推不出；真实市场参与人未必逐层理性。

- id: f05
  title: 混合策略均衡：对手无差异性计算与随机化执行
  type: reasoning_method
  source_chapter: 第7章 7.2/7.8-7.9
  source_quote: |
    "它必须让纳芙拉蒂洛娃在她的两个纯策略之间无差异。我们称之为对手无差异性质。……随机并不意味着一半时间采用一种打法，或两种打法交替进行。后者本身就是一个可以被公开利用的系统的行动。"
  summary: |
    无纯策略均衡时的解法。计算：设己方混合概率p，令对手两个纯策略的期望支付相等，解出p——这是让对手无机可乘的"利用佐证"混合；对双方各解一次得均衡。执行：交替行动本身就是模式，须用真正随机装置（如秒针法）而非"感觉随机"；零和场景中不可预测性本身是策略资产。排障：解出的概率若为负或大于1，说明博弈其实有纯策略均衡，回头找纯策略。
  stock_application: |
    对手盘思维：(1)避免自身交易模式被识别——执行层面保持真正随机，防被算法反向收割；(2)识别主力"假随机"（交替即模式）；(3)推断对手混合概率的临界值（如主力在什么概率组合下无差异），寻找对手偏离均衡的错误并利用。注意市场非零和，混合策略证据在非零和场景弱，须谨慎。
  inputs: 2×2支付表（各纯策略组合支付）、执行随机化的手段
  outputs: 各方均衡混合概率 + 期望支付 + 执行方案；负概率时回退纯策略分析的提示
  missing_conditions: 原书用实验承认非零和混合策略预测很差（仅零和体育赛事支持良好）；股票市场非零和，均衡混合的规范性基准与实证描述须区分。

- id: f06
  title: 聚点均衡选择（多重均衡排障）
  type: troubleshooting
  source_chapter: 第1章 1.2.3 / 第4章 4.6 / 第5章 5.2.2
  source_quote: |
    "关键是在特定情况下对参与人做何种选择的预期收敛（convergence of expectations）。参与人得以成功协调所依赖的这种共同预期策略称为聚点（focal point）。"
  summary: |
    症状：博弈存在多个纳什均衡，数学描述无法确定哪个会被选中。判断：均衡选择不由博弈结构决定，而由博弈外线索决定——共同文化、历史、标签、显著性。操作：寻找所有参与人都认为"对方也会认为明显"的共同线索（整数、对称点、惯例、地标），预期收敛于此即聚点均衡。验证：线索必须对双方共同可见且共同 believed 显著，否则协调失败。
  stock_application: |
    关键点位分析：整数关口、前高前低、成本线、心理价位作为自我实现的协调点——解释为何这些位置常出现真实买卖压力与波动放大。同时警惕其局限：聚点依赖共同背景，机构与散户参照系不同时聚点失效；聚点可被操纵（制造显著性吸引跟风）。
  inputs: 均衡集合、参与人共享的背景线索（文化/历史/习惯/显著数字）
  outputs: 被选中的均衡预测 + 聚点失效风险提示
  missing_conditions: 原书承认聚点理论"是一门艺术"，无法形式化；何种线索在异质参与人（机构vs散户）间收敛，原书未处理。

- id: f07
  title: 廉价磋商可信度分级（利益一致度检验）
  type: framework
  source_chapter: 第8章 8.2-8.3
  source_quote: |
    "直接沟通的可信性取决于博弈双方利益一致的程度。……共同利益越大，信息传递就越难。"
  summary: |
    判定"说出来"何时可信。操作：(1)评估说者与听者的利益一致度；(2)利益完全一致→廉价磋商有效，口头信息可信；(3)利益完全冲突（零和）→只有废话均衡，一切声明按噪声处理，且不要机械反着读（"她说A"≠"她会做非A"）；(4)部分一致（如投资顾问拿佣金不分担损失）→话语系统性偏向某方向，只能相信其中利益一致的子区间（分割披露）：报告的粗分区可信、细分不可信；(5)说者声誉成本越高，分割越细。关键依赖：双方对利益关联程度的认知须是共同知识。
  stock_application: |
    直接同构的信息过滤器：卖方研报、财经自媒体、公司IR沟通按佣金/流量结构分级——只赚流量不分担亏损者话语系统性偏向看多；完全对赌的对手方声明按噪声处理；利益完全一致者（如自家回购且披露明细）声明可部分采信。对任何荐股先问"他靠什么赚钱、亏了我他亏什么"。
  inputs: 信息发布方的收益结构（佣金/分成/声誉成本/损失分担）、与接收方利益的一致度
  outputs: 可信度分级（可信/系统性偏误/纯噪声）+ 可采信的子区间
  missing_conditions: 声誉成本数值需外部估计，原书只给教学数字；对"分割到多粗才可信"只给方法论，无通用量化公式。

- id: f08
  title: 信号差异成本检验与甄别机制设计
  type: framework
  source_chapter: 第8章 8.4-8.6
  source_quote: |
    "教育能区分类型的关键要求是教育对于不熟练工人的成本要远远高于熟练工人。"
  summary: |
    不对称信息下"行动胜于语言"。信号传递检验（信息优势方视角）：一个行动是可信信号，当且仅当满足差异成本条件——真实类型执行该行动的成本显著低于伪装类型，使模仿不划算；无成本差异的声明（口头宣称、可轻易转移的装饰）一律无效。甄别设计（信息劣势方视角）：提供菜单式选项，让不同类型自选择暴露（激励相容）。若两者皆缺→混同均衡/逆向选择，市场可彻底崩溃（柠檬市场：好车占比低于临界值则交易消失）。
  stock_application: |
    管理层行为可信度评级：回购+注销（真金白银、Fake成本高）>口头乐观指引（零成本，默认无效）；大股东高位质押变动、业绩指引后真金兑现、通胀指数化债务承诺（原书例）逐一过差异成本检验。打新/定增询价中识别逆向选择：热门标的"中标"本身可能是坏消息信号。政府与企业披露机制设计用甄别菜单思路解读。
  inputs: 信号行动清单、各类型执行/模仿该行动的成本、类型先验分布
  outputs: 信号可信度评级（有效/无效）+ 分离或混同的均衡判断 + 逆向选择临界提示
  missing_conditions: 差异成本的具体数值需外部估计；贝叶斯更新计算普通投资者难以精确执行（原书承认人们不善于条件概率计算）；未覆盖支付非线性与监管强制披露环境差异。

- id: f09
  title: 策略性行动分类与先行动双条件检验
  type: framework
  source_chapter: 第9章 9.1-9.2
  source_quote: |
    ""先行动"包含了两方面的含义：首先，你的行动对于别人来说必须是可观察的（observable）；其次，它是不可逆的（irreversible）。"
  summary: |
    评估一方试图改变博弈本身（而非在给定博弈内行动）时的框架。分类：无条件行动=承诺（"不管你做什么我都做X"）；条件行动=反应规则，分威胁（你不顺从则伤害你）与许诺（你顺从则奖励你），目标又分遏制（阻止做某事）与强迫（引导做某事）。先行动合法性检验：可观察（对手看得见，否则等于没做）+不可逆（可反悔则对手不响应）。置信度核心：威胁必须"互相伤害"——实施威胁对威胁者自己有代价才可信；若实施威胁本来就是威胁者的最优反应，则根本无需威胁。
  stock_application: |
    央行/大股东/庄家行为解读：前瞻指引=许诺、加息放风=威胁、长期资金承诺=承诺；逐一过"可观察+不可逆"检验（口头指引可逆性高，立法/程序性承诺不可逆性高）；"威胁成功则不必执行"用于解读"只闻楼梯响"的政策威慑。识别对手的策略性行动企图是防御第一步。
  inputs: 声明/行动内容、可观察性证据、不可逆性证据、各方支付结构
  outputs: 策略性行动类型标签（承诺/威胁/许诺×遏制/强迫）+ 置信度初判
  missing_conditions: 可观察与不可逆只有定性标准，无可操作打分表；原书例多为国家与企业，个人投资者作为小参与人的观察渠道限制未讨论。

- id: f10
  title: 威胁与许诺的量化设计规则（含暗含许诺检查）
  type: framework
  source_chapter: 第9章 9.4
  source_quote: |
    "如果威胁成功了，它就不必实施了，威胁者就不用付出代价。所以威胁可以比所需的更大……如果许诺成功地如自己所愿改变了他人的行动，那么许诺人必须做他已经许诺的事情。"
  summary: |
    设计或解读条件反应规则的规则集：(1)威胁成功则不执行→威胁可适度夸大以增效果，但夸大有失控风险；(2)许诺成功则必须兑现→许诺代价只需大到有效即可，不必更大；(3)每个威胁暗含一个许诺（"你不违约我就不惩罚"），每个许诺暗含一个威胁；若暗含部分不自动可信，必须把两者都明确化并分别建立置信度，否则威胁退化为无条件承诺；(4)遏制宜用威胁（静态、无需时限），强迫宜用许诺（否则被腊肠策略拖延）；(5)可通过改变现状把威胁转换为许诺。
  stock_application: |
    政策组合拳解读：监管"威慑+安抚"组合（处罚个案=威胁，明确准入规则=许诺）是否配套、暗含许诺是否可信；公司"业绩不达标则高管降薪"条款的暗含部分（达标则有奖励）是否自动可信；判断声明者是要遏制（阻止某行为）还是强迫（推动某行为），从而预判其后续工具选择与时间压力。
  inputs: 声明内容、暗含的反向规则、各方支付、是否附时限
  outputs: 威胁/许诺设计缺陷清单 + 需补齐置信度的部分 + 遏制/强迫定性
