# 机制设计与激励契约

## R 原文
"信息劣势方要为信息优势方创造出动机从而使得信息优势方的行为有利于信息劣势方……委托人用来激励代理人正确动机的程序就是所谓的机制设计（mechanism design）。"（第13章章首，L8769）"委托人的机制必须与代理人的激励保持一致……这就是所谓的激励相容约束……这种代理关系给予代理人的期望效用必须至少与他从其他地方……获得的相等。"（13.2，L8851）"PITS的定价策略受制于一般乘客的参与约束和商务乘客的激励相容约束……让X尽可能地靠近140，让Y尽可能地靠近215。"（13.1，L8825）

## I 自述
核心骨架（委托人视角的两类问题，统一约束框架）：
1. 问题分型：信息披露型（逆向选择）——代理人知道自己的类型（成本/支付意愿/质量），机制要诱其"自选择"暴露类型，即甄别（screening via self-selection），是f08信号差异成本检验的设计者反向应用；道德风险型——代理人行动不可观察（努力/维护），机制要诱出最优行动水平。
2. 双约束（一切机制的通用语法）：激励相容约束（IC）——给定机制，每类代理人如实报告/真努力是最优反应，伪装无利可图；参与约束（IR）——接受机制的期望效用≥外部选项效用。IC与IR同时以等式成立时机制最优。
3. 甄别菜单解法（公路例）：设两份契约L（低成本型）与H（高成本型）——IR_H：R_H≥5N_H；IC_L：R_L−3N_L≥R_H−3N_H（低成本型不冒充高成本）。低成本型得到"信息租金"（胡萝卜），高成本型契约被压缩产量（大棒）以削弱伪装收益——扭曲效率换取可甄别性。
4. 努力激励解法（经理例）：契约（失败付x、成功付y）须同时满足IC：(1/2)√y+(1/2)√x−0.1≥(1/4)√y+(3/4)√x与IR：(1/2)√y+(1/2)√x−0.1≥0.3；解得x=40000、y=360000（基本工资+成功奖励320000即利润的32%）；纯奖金（x=0）因代理人风险厌恶反而更贵（利润18万<30万）——激励强度与风险分担的权衡是道德风险契约的核心。
5. 非线性与时间激励扩展（13.6）：定额奖金激励强但可操纵（窗口期末懈怠、跨期转移订单），通常与分段线性佣金混用；团队激励用相对业绩（共同随机项r相消）；多任务下强激励任务会抽走弱激励任务的努力（教授科研vs教学例）；效率工资w≥w₀+er/p防怠工。
6. 投资者映射：读管理层激励（股权激励行权条件、对赌条款、基金费率结构）=读"机制在激励什么"；打新/定增询价机制=委托人的甄别菜单设计。

## A1 案例
类型：textbook数值例，来源：第13章13.1、13.3、13.5（合并转写稿L8789-8935、L8965-9041）
例一（成本加成vs固定价格甄别菜单，13.3）：公路V=15N−N²/2，车道成本3或5（十亿），先验概率2/3与1/3。完全信息：成本低修12车道付36、成本高修10车道付50。非对称信息下两份固定总价契约会被低成本型套利（选H得200亿超额）。最优甄别菜单：契约L=修12车道付48（信息租金=480−360=120亿，奖励如实报低价）、契约H=修6车道付30（产量扭曲10→6，压低伪装收益至120亿正好抵消胡萝卜）；被忽略的IC_H验证：30−5×6=0≥48−5×12=−12成立。例二（努力激励，13.5.1）：项目利润100万、好管理成功率1/2、差1/4，经理u=√y、努力成本0.1、外部效用0.3。IC：√y−√x≥0.4；IR：√y+√x≥0.8。联立解Y=0.6、X=0.2→x=40000、y=360000，所有者期望利润Π=(1−0.36−0.04)/2=0.30即30万，比可强制努力契约的34万少4万=信息不对称的不可避免成本；纯奖金y=64万时利润仅18万。数值与转写稿一致，V2复算通过。

## A2 触发
股票场景与语言信号（中英双写关键词）：
1. "这份股权激励方案会催做什么？"（incentive misalignment / vesting terms）→ 读IC：行权条件、业绩门槛决定管理层行动方向，非口号。
2. "对赌协议里谁是委托人？"（VAM / earnout design）→ 识别双约束是否齐备：缺IC则条款被套利，缺IR则无人签约。
3. "定增询价底价怎么设计才筛得出长线资金？"（bookbuilding screening）→ 甄别菜单：锁定期=扭曲产量的大棒，折价=信息租金。
4. "基金经理费率结构会诱导什么行为？"（fee structure incentive）→ 高水位/非对称费率的IC分析；凸奖励诱导过度冒险（13.6.1基金例）。
5. "供应商/被投企业虚报成本怎么办？"（cost padding / adverse selection）→ 判成本加成还是固定价格：信息租金与产量扭曲权衡。
与相邻卡区分：celue-05是投资者侧的"读信号"（差异成本检验、判分离/混同均衡），本卡是设计者侧的"造机制"（给定双约束解契约参数）——同一枚硬币的两面，读完机制回头用05验证其可置信度；celue-02找既定博弈的均衡，本卡改变博弈规则本身（rules are endogenous，对应celue-00第5问"规则可否操纵"）；celue-03的激励是重复博弈触发策略（时间维度），本卡是单期契约设计。

**相邻区分（定稿）**：与 celue-05 的区分（定稿）：celue-05 是投资者侧"读信号"（给定机制判信息含量与可信度），本卡是设计者侧"造机制"（给定 IC/IR 双约束解契约参数）——同一枚硬币的两面：读完条款设计回头用 05 验证其可置信度。
## E 执行
1. 定角色：谁是委托人（信息劣势/规则设计方）、谁是代理人（信息优势/行动方）；列出代理人类型集或行动集（离散两型/两努力水平起步）。
2. 列支付：各类型/各努力水平下的成本、收益、外部选项效用u₀；支付单位统一并留来源。缺外部选项效用→先问（IR无法写出），不代填。
3. 写双约束：IR——接受契约的期望效用≥u₀（逐类型/逐努力水平）；IC——如实类型（或高努力）的支付≥伪装（或偷懒）的支付。公式（两型两契约）：IR_H：R_H≥c_H·N_H；IC_L：R_L−c_L·N_L≥R_H−c_L·N_H。道德风险（成功付y失败付x、成功率p_H/p_L、努力成本e、外部效用u₀）：IC：p_H√y+(1−p_H)√x−e≥p_L√y+(1−p_L)√x；IR：p_H√y+(1−p_H)√x−e≥u₀。
4. 求解：设约束以等式成立联立（IC与IR同时取等）；对产量/努力变量用最大化形式X=B/(2C)（二次目标）；回代验证被忽略的约束确实松弛。
5. 读结果：信息租金=低成本型的超额支付（胡萝卜）；扭曲量=高成本型产量/努力低于完全信息水平（大棒）；信息不对称成本=非对称最优利润−完全信息利润。
完成标准：双约束均以数学式写出并解出；契约参数（价格/产量/工资/奖金）可复算；信息租金与扭曲量两项都有数值；被忽略约束回代验证通过。
判停点：类型或努力水平的支付无法量化且拒绝估计→退化为"约束检查表"（该机制缺哪条约束），不给数值契约；代理人为多人且相互合谋可行→相对业绩机制失效，判停（书中明确合谋可粉碎比较机制）。
输入契约：委托人目标函数、代理人类型/努力分布、各状态支付与成本、外部选项效用u₀、可观察变量清单（什么可验证）。
输出契约：契约参数组（各类型/各状态的支付与要求）+信息租金+扭曲量+信息不对称成本+双约束验证过程；数值保留两位小数，误差≤±2%（支付估计所致，须声明）；不给买卖建议。

## B 边界
反场景：双方信息对称且行动可观察→直接第一优契约（按成本加成足额补偿），无机制设计问题；代理人单一人决策无委托关系→普通决策优化；纯信号解读（我方是信息劣势方且无法改规则）转celue-05。
书中警告的失败模式：甄别菜单对类型比例敏感——商务乘客占比升至50%时放弃甄别、只做高利润档更优（13.1末，L8828-8836），投资者映射：长线资金占比变化会令锁定期机制的优劣反转；定额奖金的反常激励（期末懈怠、跨期操纵订单，13.6.1）；纯奖金迫使风险厌恶代理人索要高额补偿（利润18万vs30万）；多任务强激励抽空弱激励任务（13.6.3）——公司若只按可验证指标激励（如短期利润），不可验证的长期价值（声誉、合规）必然被牺牲。
阶段0批判中的作者盲点：本卡已登记 Bundle（router 去向，经 celue-00-source-router 路由访问；verified.yaml 与 destinations.json 均已收录本卡条目）；书中只解两型两契约与单一努力水平，真实类型连续、行动多维时解析解不存在；假定委托人有完全承诺力（契约可第三方执行），管理层自我交易场景中委托人缺位；风险厌恶用√效用例证化，代理人真实效用含职业声誉与流动性约束；未处理动态 renegotiation（契约可再谈判时大棒条款的可信性存疑，与celue-07反制逻辑联动）。
易混淆相邻方法论：与celue-05区分（读信号vs造机制，投资者日常是前者，本卡用于评估条款设计与参与定增条款博弈）；与celue-10区分（拍卖是竞争性机制、本卡是双边契约机制，同属机制设计但解法不同——维克里说真话是本卡IC思想在拍卖上的特例）；与celue-11区分（谈判分配既定剩余、机制设计先改变可分配的规则）；与公司金融的委托代理理论同源，本卡限定书内契约算例。
