# 支付表与纳什均衡定位

## R 原文
"最优反应分析是一种全面寻找博弈中所有可能的纳什均衡的方法。"（第4章4.4，L1679）"重复剔除弱劣策略可能会遗漏一些纳什均衡。……如果你运用了弱占优来剔除某些策略，最好还是用其他方法检查一下。"（第4章4.3.3，L1649）填写约定："两个支付数值中的第一个是'行'的支付，第二个是'列'的支付。"（第4章，L1494）

## I 自述
核心骨架：
1. 画表：行=一方、列=另一方；格内两数"先行后列"；支付方向显式注明（利润/损失/收益率必须同口径）；三人博弈需第三维"页"。支付应是净期望收益，须把尾部损失与风险计入（见B，x05）。
2. 占优剔除做快速减法：某策略在对手每种选择下都严格更差→剔除（强占优安全）；重复剔除直到不能剔，仅剩唯一结果即占优可解。弱占优（存在相等支付）剔除不安全，剔后必须复查。
3. 最优反应分析逐格双向圈定：固定列的每个策略，找行的最优反应格圈行标；固定行，找列的最优反应圈列标；双重圈定的格子=纳什均衡（互为最优反应）。这是全面法，一个均衡都不漏。
4. 无双重圈格→不存在纯策略均衡，转混合策略（celue-04）。
5. 解读三件事：均衡格在哪、当前市场价隐含哪个格、均衡格是否是双输格（囚徒困境型"理性但双输"）；多重均衡并存时转聚点（celue-06）。
6. 弱占优复查纪律：凡用过带等号的剔除，逐格回查全部均衡——平局情景（支付相等）往往正是横盘对峙的关键状态。

## A1 案例
类型：business，来源：第4章4.3.2表4-5 国会vs美联储（candidates/cases.md c01；阶段1.5 f03/f04 walkthrough 复算）
国会{平衡,赤字}×美联储{高利率,低利率}，支付：平衡/低(3,4)、平衡/高(1,3)、赤字/低(4,1)、赤字/高(2,2)。占优解法：国会"赤字"占优（对手任一选择下4>3、2>1）→美联储预判后选高利率，均衡（赤字,高利率）=(2,2)；但（平衡,低利率）=(3,4)对双方更优——囚徒困境"理性但双输"。最优反应复算：选低利率列→国会最优反应赤字（4>3）；选高利率列→仍赤字（2>1）；国会选平衡行→美联储低利率（4>3）；选赤字行→高利率（2>1）；双重圈唯一=（赤字,高利率），与 L1630-1632 一致。
类型：business，来源：第6章6.1图6-2 联邦快递vs联合包裹机场投资（c04）：两个纯均衡各需一方投资一方不投，现实更可能"双双投资而亏损"——扩产博弈周期底部的博弈论解释。

## A2 触发
股票场景与语言信号（中英双写关键词）：
1. "利好落地为什么反而跌、理性怎么还双输"（prisoner's dilemma / rational sell-off）→ 支付表找双输均衡格。
2. "两个主力/两路资金互相怎么猜"（guessing game / simultaneous moves）→ 互为最优反应分析。
3. "光伏锂电扩产竞赛谁先眨眼"（capacity race / chicken game）→ 双均衡懦夫结构+双双投资过均衡预警。
4. "这定价已隐含了哪种情形"（priced-in scenario）→ 用均衡格对照当前格识别偏离。
5. "用排除法排掉了几个情景"（elimination reasoning）→ 检查是否用了弱占优，触发复查。
与相邻卡区分：celue-00 只分类不找均衡；celue-01 处理序贯树；celue-04 是本卡"无纯均衡"时的下游（混合概率）；celue-06 是"多重均衡"时的下游（收敛到哪个）；celue-08/12 是多人/进化版拥挤问题，不是双人表。

## E 执行
1. 填表：确定两方、各2-N个策略；按"先行后列"填数，注明支付方向与口径。缺一方支付→先问用户补齐，禁止用对称假设代填。
2. 占优减法：先找强占优安全剔除；遇弱占优（含相等支付）先标记、可剔除但必须留待步骤4复查。
3. 最优反应圈定：逐列圈行最优反应、逐行圈列最优反应；双重圈格=全部纯策略纳什均衡。
4. 弱占优复查：对每个被弱剔除的策略逐格重检，列出被漏掉的均衡（x04表4-6：剔除后只剩（下,右），复查补回（下,左）（上,右））。
5. 解读：当前格vs均衡格偏离方向+是否存在更优共同结果+多重均衡是否需要聚点分析。
完成标准：每个格都有两向最优反应标记；均衡清单完整（含复查补回项）；支付口径声明在案。
判停点：策略空间无法穷举（连续变量）→转 celue-09/11 的连续处理或说明本卡退化为定性最优反应；支付含极端尾部值（爆仓/退市）→先做x05式风险态度修正再定位，不让一个-1000被期望值抹平。
输入契约：双方策略清单+各方各格支付（或可排序的偏好）；缺先问。
输出契约：支付表+均衡格坐标+当前格偏离诊断；计算容差：支付数值误差±5%内均衡定位不变的须声明"稳健"；弱占优复查结果必须显式列出。

## B 边界
反场景：序贯博弈直接画2×2同时表会丢先动优势（应转 celue-01 建树）；参与人>2且策略互动复杂时支付表爆炸，转 celue-08/12。
书中警告的失败模式：x04 弱占优漏均衡（表4-6罗伊娜-科林，带等号剔除悄悄丢掉平局情景——恰是横盘对峙关键状态）；x05 纳什均衡忽略风险态度（摩根/克雷普斯博弈：只要对手支付有1/1009概率与表相反，-1000尾部风险就使"唯一均衡"不再该选——支付表须写入爆仓线与非线性尾部，这是书中自认未处理、须外补的地方）。
阶段0批判中的作者盲点：支付数值客观可得是幻觉——真实市场各方支付（基金经理的考核期、大股东的质押线）互相不可观测且随时间变化；均衡假设参与人同时正确计算，忽略学习与试错过程；风险中性隐含在数字比较中，与真实仓位约束脱节。
易混淆相邻方法论：与决策论收益矩阵（无对手互为最优反应环节）区分；与 celue-04 混合策略（本卡无双重圈格时的下游，注意x03非零和警示）；与 celue-06 聚点（多重均衡已找到之后的收敛方向问题）；p02填写规范、p03逐格检查法与弱占优警告（rejected）已并入本卡 I/E 段。
