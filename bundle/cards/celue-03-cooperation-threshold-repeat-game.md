# 合作临界值计算（重复博弈与瓦解时点）

## R 原文
"当我们将p纳入考虑之中时，未来支付的有效贴现因子是p×δ，而不是δ。我们将R称为有效收益率（effective rate of return），R满足1/(1+R)=p×δ……则R=(1-0.5×0.95)/(0.5×0.95)=1.1或110%。"（第10章10.2.3，L6631-6640）"参与人背叛一次……仅当(1+R)(H−C)>C−L"→"R > (C−L)/(H−C) − 1"；"如果永久背叛得到的一次收益超过了未来各期损失现值的无穷级数和……即 (H−C) > (C−D)/R"→"R > (C−D)/(H−C)"（第10章10.2.4，L6661/L6665）；支付结构须满足 H>C>D>L。

## I 自述
核心骨架：把"抱团/联盟能撑多久"翻译成背叛是否划算的收益率比较。
1. 支付四元组：H（单方背叛的高收益）、C（双方合作的支付）、D（双方都背叛的支付）、L（被背叛方的低收益），须满足 H>C>D>L。
2. 有效收益率折算（p13要点，本卡E段公式）：真实贴现因子 δ=1/(1+r)；博弈下期延续概率 p；有效贴现=pδ；有效收益率 R=(1−pδ)/(pδ)。p=1时退化为R=r。
3. 双临界：一次背叛临界 R¹=(C−L)/(H−C)−1；永久背叛临界 R∞=(C−D)/(H−C)。当前R超过任一临界→对应背叛策略划算，合作瓦解。
4. 判读：R随 r 上行、p 下修而变大——"利率上行+关系存续预期恶化"是背叛诱因的先行指标；H−C 越大（背叛诱惑越强）临界越低、合作越脆。
5. 有限重复终点效应（x10）：已知到期日的重复博弈从最后一期开始逆推瓦解，逐期前传；除非把大博弈拆成小块分期、或注入外部激励。
6. 以牙还牙、触发策略是合作的执行机制；领导（大玩家利益强绑定）可进一步稳住合作（c10沙特例）。

## A1 案例
类型：business（书中餐馆例+一般式复算，阶段1.5 f12/p13 walkthrough）
餐馆例：每期合作利润相对背叛的得失使 C−D=36、H−C=36 → 永久背叛临界 R=36/36=1（即100%）。r=5%、p=0.5 时 R=(1−0.5×0.9524)/(0.5×0.9524)≈1.10=110%>1 → 背叛划算、以牙还牙合作瓦解，与转写稿 L6640/L6642 完全一致。一次背叛临界 =(C−L)/36−1 同法可算。
类型：business，来源：第10.3章 OPEC沙特"摇摆者"（cases.md c10）：小成员扩产时沙特减产保价——大玩家背叛时大部分伤害落在自己头上，支付不对称使其即使短期吃亏也维持合作；大玩家退出信号是联盟拐点最优先指标。
类型：history，来源：奥斯陆和平进程1998中断（counter_examples.md x10）：末期临近→双方置信度崩塌→合作中断；解法=分期推进+外部援助注入。

## A2 触发
股票场景与语言信号（中英双写关键词）：
1. "这个板块抱团/联盟还稳不稳、何时散伙"（crowding coalition / when does it break）→ 套四元组算双临界。
2. "OPEC式供给联盟/行业保价协议能撑多久"（cartel stability）→ H−C诱惑与R比较。
3. "限售解禁、对赌到期前会不会抢跑"（lockup expiry / endpoint effect）→ 终点效应时点清单（x10）。
4. "资金利率上行对抱团意味着什么"（discount rate rising / crowding unwind）→ r上行推高R逼近临界，先行指标。
5. "龙头（庄家/大玩家）退出的信号怎么看"（bellwether exit）→ 领导机制：大玩家动摇比小成员背叛更值得作为拐点。
与相邻卡区分：celue-01 逆推回答"事件路径怎么走"，本卡回答"合作在什么收益率/存续概率下瓦解"（数值临界）；celue-08 处理人数维度的临界规模，本卡是两方支付结构的收益率维度；celue-12 是进化稳定版（类型比例维度）；celue-10 的中标校验是一次性拍卖问题，无重复合作结构。

**相邻区分（定稿）**：与 celue-12 的区分（定稿）：本卡是重复博弈的收益率临界（时间维度：R 对双临界，问"利率上行后合作还能撑几期"），celue-12 是进化博弈的类型比例临界（空间维度：适应度阈值族，问"策略种群比例何时越过瓦解点"）——前者需 H/C/D/L 四元组，后者需 V/C 与阈值族，参数与公式均不可互代。
## E 执行
1. 标定四元组：从行情/财报/协议条款估计 H、C、D、L（可用单期超额收益、违约收益、均势利润、被弃后的损失近似），并声明来源；缺任一项→先问用户，不代填。
2. 折算有效收益率：δ=1/(1+r)，R=(1−pδ)/(pδ)；p=关系/行情延续概率（历史抱团存续期、协议剩余期估计）；p=1时 R=r。
3. 双临界比较：算 R¹=(C−L)/(H−C)−1 与 R∞=(C−D)/(H−C)；R>R¹→一次背叛已划算（警惕抢跑）；R>R∞→永久背叛划算（合作必散）；两者取先触发者作为瓦解先行指标。
4. 终点修正：若存在已知到期日（解禁日/对赌到期/封闭期），对最后几期直接判背叛概率系统性上升，不经公式。
完成标准：H>C>D>L校验通过；R与双临界均给出数值；结论表述为"当前R=x%，距一次背叛临界y%、距永久背叛临界z%"。
判停点：四元组无法标定且用户拒绝赋值→输出定性方向（r↑/p↓/诱惑↑均促瓦解）并声明不可复算；发现对手非以牙还牙/触发策略型（如一次性流量资金）→本卡前提失效，转 celue-02。
输入契约：H/C/D/L估计值+来源、r（无风险或资金成本）、p（延续概率）及依据、到期日清单。
输出契约：公式与容差——R=(1−pδ)/(pδ)，R¹=(C−L)/(H−C)−1，R∞=(C−D)/(H−C)；δ=1/(1+r)；数值保留4位小数后比较；输入p、r误差±10%时给出R的敏感性区间；结论须注明主导变量（是p下修还是r上行在驱动）。

## B 边界
反场景：一次性博弈（IPO打新单次报价、单次对倒）无合作可谈；对手收益结构不满足H>C>D>L（如互相成就的正和关系）临界公式不适用。
书中警告的失败模式（x10，第10.2.1/9.6.2）：有限重复终点瓦解——奥斯陆进程在最后阶段到来时"双方下一步行动的置信度出现了问题"于1998年中断；解法是把博弈分成许多小块分期执行、或引入外部激励注入。纪律：距终点的剩余时间是合作概率的衰减变量，必须纳入持仓周期管理。
阶段0批判中的作者盲点：p（延续概率）被当作外生常数，真实市场里一次瓦解事件本身会改变所有人的p（内生崩塌、自我实现）；支付四元组默认各方可准确感知，而信息不对称下被背叛方往往事后才知道H；以牙还牙假定惩罚精确一次性，市场报复常过度或不足。
易混淆相邻方法论：与 celue-08 临界人数（P(n)/S(n)曲线，人数维度）区分——本卡无需人数曲线、只需支付与利率；与 celue-12 ESS适应度阈值（x>2/n随持有期拉长而降，类型比例维度）互补而非重复；p13有效收益率公式、p14双临界公式（rejected）已全部并入本卡R/I/E段。
